# 🎓 四六级智学 · 备考智能体

一个**纯离线、免安装**的大学英语四六级备考应用。下载后双击 `index.html` 即可使用，
全程本地运行：**不联网、不登录、不收集任何数据**。

> 围绕「测 - 学 - 练 - 考 - 评」完整闭环，覆盖入门基础、专项强化到冲刺模考的全备考周期，
> 精准击中大学生备考核心痛点：**单词背了就忘、阅读做不完、写作翻译没人改、备考无规划**。

**在线试玩**：https://yilinpj-god.github.io/cet-study/ （开启 Pages 后自动更新；在线版额外支持 PWA 安装到桌面/手机主屏）

## 📦 下载使用

### 方式一：下载 ZIP（推荐）

1. 到 [Releases](../../releases) 页面下载最新版 ZIP
2. 解压到任意文件夹
3. 双击 `index.html`（推荐 Chrome 或 Edge 浏览器）

### 方式二：克隆仓库

```bash
git clone https://github.com/<你的用户名>/cet-study.git
```

然后双击其中的 `index.html`。

### 数据保存在哪里？

存在**这台电脑的浏览器**里（localStorage + IndexedDB），刷新、关闭、重启都不丢。
换电脑或清浏览器缓存前，先在「首页看板 → 数据安全」**导出备份** JSON，
到新环境「导入备份」即可完整迁移。

## 🚀 发布到 GitHub（维护者指南）

1. 在 GitHub 上新建一个空仓库（不要勾选自动生成 README）
2. 在项目目录执行：

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

3. 发新版本：仓库页 → Releases → Draft a new release →
   创建 Tag（如 `v1.1.0`）→ 把 `release/` 目录下的 ZIP 拖进来 → Publish

可选：在仓库 Settings → Pages 中开启 GitHub Pages（选 main 分支），
还能得到一个在线访问地址，方便在手机/其他电脑上试玩（数据仍只存浏览器本地）。

## 🧪 开发与测试

项目为纯 HTML/CSS/JS，无构建步骤、零依赖。本地起个静态服务器即可开发调试：

```bash
python -m http.server 8765
```

自动化端到端测试套件：`tools/e2e-suite.js`（36 个用例，覆盖引导流程、
词汇五种模式与自定义导入、听力播放/回看/降级、阅读延期查词、数据备份校验、
PWA 资源完整性等），可在浏览器控制台注入后逐例运行，详见文件内注释。

常见问题见 [docs/FAQ.md](docs/FAQ.md)；贡献词库/题库请读 [CONTRIBUTING.md](CONTRIBUTING.md)。
