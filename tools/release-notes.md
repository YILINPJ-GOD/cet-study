# 四六级智学 v1.2.0 · 批改可视化 + 数据安全 + 词汇/听力增强

## 🆕 新功能

- 📊 **批改报告可视化**：写作批改新增六维度雷达画像（篇幅/结构/衔接/句式/用词/拼写），写作与翻译历史成绩成长曲线
- 🛡️ **数据安全强化**：备份导入深度校验（防损坏文件）；导入前自动导出当前数据作应急备份；超过 7 天未备份首页提醒
- 🔊 **发音口音切换**：美音 / 英音可在首页设置
- 📥 **自定义词库导入**：支持 CSV/TXT 生词表（单词,音标,词性,释义），自定义词优先进入每日背词队列，可筛选管理
- 🎧 **听力增强**：交卷后解析标注"定位句"并在原文高亮；随时回看上次作答（无需重做）
- 📲 **PWA**：在线版（GitHub Pages）可安装到桌面/手机主屏，首次访问后全资源离线缓存
- ⚙️ GitHub Pages 自动部署工作流；新增 FAQ 与贡献指南；E2E 测试扩充至 36 例

## 📦 下载使用

下载下方 Assets 中的 `cet-study-v1.2.0.zip` → 解压 → 双击 `index.html`（推荐 Chrome/Edge）。
纯离线运行，无需安装、无需联网、无需登录；学习数据只保存在本机。

## ⬆️ 升级说明

从 v1.1.x 覆盖安装即可，学习数据自动保留；如需迁移，使用「首页 → 导出/导入备份」。
