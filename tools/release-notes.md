# 四六级智学 v1.7.0 · 真题中心 + 词根全集 + 句子翻译训练 + 智能出题

## 🆕 本版亮点（v1.3 → v1.7 累积）

- 📜 **真题中心**：汇总第三方公开真题资源站（四级 28 考次 / 六级 27 考次 / 各 76 套整卷含解析版）；
  支持导入你自行下载的真题 PDF 与听力音频到本机（IndexedDB，重启不丢）；
  真题刷题分数录入与统计（平均分/最高分/425 及格线徽标）。App 不收录不分发任何真题内容。
- 🏛 **真题全卷模式**：写作 30′ → 听力 30′ → 阅读 40′ → 翻译 30′，共 130 分钟，
  完整对标真卷结构与 710 分制折算，含听力盲听作答分区
- 🧩 **词根词缀全集**：89 词根 / 56 前缀 / 36 后缀，拆解推断练习 + 查词自动拆解 + 搜索
- ✏️ **句子翻译 AI 训练**：40 句真题风格句子，写出英文即时评分（关键表达核对 + 修改意见）
- 🎯 **智能出题生成器**：6 大主题（科技/环境/教育/健康/社会/文化），支持难度选择与
  "结合我的生词本出题"；每日自动补充新题，刷完不枯竭
- 📝 入学测试三类题型（单词/短语/句子语境）+ 交卷逐词回顾；四六级可随时互切
- 📈 批改报告雷达图与成长曲线；数据备份深度校验与应急备份
- 📲 PWA：在线版可安装到桌面/主屏，全资源离线缓存

## 📦 下载使用

下载下方 Assets 中的 `cet-study-v1.7.0.zip` → 解压 → 双击 `index.html`（推荐 Chrome/Edge）。
