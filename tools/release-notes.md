# 四六级智学 v1.1.0 · 首个公开版本

纯离线、免安装的大学英语四六级备考应用。

## 📦 下载使用

1. 下载下方 Assets 中的 `cet-study-v1.1.0.zip`
2. 解压到任意文件夹
3. 双击 `index.html`（推荐 Chrome 或 Edge 浏览器）

无需安装、无需联网、无需登录，所有学习数据只保存在你自己的电脑里。

## ✨ 功能一览

- 🧭 四级/六级选择 + 5 分钟入学测试（自动定级生成每日计划，交卷后逐词回顾对错）
- 📚 分级词库（常用/高频/冲刺 + 翻译写作主题词、听力场景词专项库）· 常考释义优先 · 五种记忆模式 · 艾宾浩斯间隔重复
- 🎧 听力专项（四六级分题型刷题 + 真题音频导入，支持 0.5×~2× 变速、逐句循环、AB 复读精听）
- 📖 阅读三题型专项（仔细阅读/长篇匹配/选词填空，限时训练 + 做题查词不打断）
- ✍️ 写作 8 话题范文/模板/句式 + 本地 AI 批改
- 🀄 翻译 9 篇（三主题）+ 关键表达核对 + 积累本
- ⏱ 限时模考（按六级分值折算预估分）
- 📊 打卡日历、学习时长、正确率趋势看板
