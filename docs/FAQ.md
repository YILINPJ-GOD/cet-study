# ❓ 常见问题（FAQ）

## 数据与隐私

**Q：我的学习数据存在哪里？会不会丢？**
A：存在"这台电脑 + 这个浏览器"的 localStorage 和 IndexedDB 里，刷新、关闭、重启电脑都不丢。但清浏览器缓存、重装系统、换电脑会导致丢失——**定期到「首页看板 → 数据安全」导出备份 JSON**，App 超过 7 天未备份也会提醒你。

**Q：换电脑 / 换浏览器怎么迁移数据？**
A：旧环境导出备份 JSON → 新环境首页「导入备份」。导入前 App 会自动把当前数据再导出一份应急备份，不用担心误覆盖。

**Q：用不同浏览器打开，数据互通吗？**
A：不互通。每个浏览器的存储是独立的。请固定用同一种浏览器。

**Q：App 会上传我的数据吗？**
A：永远不会。App 无任何网络请求代码，数据只在本地。GitHub Pages 在线版的静态页面由 GitHub 托管，但学习数据仍只存于你浏览器本地。

## 功能使用

**Q：点 🔊 没有声音？**
A：发音使用系统内置语音。首次点击请等 1-2 秒再点；仍无声请检查系统是否安装了英语语音包（设置 → 时间和语言 → 语音）。可在首页设置切换美音/英音。

**Q：听力真题音频怎么导入？**
A：进入听力专项 → 打开某套题 → 点「⬆ 导入原音文件」选择你持有的 MP3 等音频。文件保存在本机 IndexedDB（http/https 环境），重启不丢。**双击 file:// 直开时浏览器禁用本地数据库**，此时音频导入不可用（可改用"系统朗读演练"），建议在线版或本地服务器方式使用听力导入功能。

**Q：逐句循环提示"尚未校准"？**
A：先打开「校准句起点」开关，播放音频时在每个句子开头点「设为起点」，全部标完后即可逐句循环、AB 复读。

**Q：怎么导入我自己的生词表？**
A：词汇记忆 → 词库 → 「⬆ 导入自定义词」。支持 CSV/TXT，每行一个词（可选音标、词性、释义，逗号或 Tab 分隔）。导入的词优先进入每日背词队列，可在词库里筛选"我的词库"管理。

**Q：写作批改的分数准确吗？**
A：本地批改引擎从篇幅、结构、衔接、句式、用词、拼写六个维度规则化评分，适合日常训练定位问题；与真人阅卷存在差异，冲刺阶段请以真题范文对照为准。

## 故障排查

**Q：双击 index.html 打不开或白屏？**
A：请确认用 Chrome/Edge 等现代浏览器；不要把 index.html 单独移出文件夹（需要同目录的 css/js 资源）。

**Q：刷新后进度丢了？**
A：大概率是换了浏览器或用了无痕模式（无痕模式关闭即清空）。日常请用正常窗口。

**Q：升级新版本会丢数据吗？**
A：不会。数据与程序分离存储，用新版文件覆盖旧文件夹即可，学习记录自动保留。
